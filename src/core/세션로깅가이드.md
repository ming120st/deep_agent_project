# 세션 & 태스크 로깅 연동 가이드

`src/core/session_logger.py` 를 사용하여 모든 대화 흐름을 `session_logs` 컬렉션에 기록합니다.

---

## 구조 개요

```
session (GraphState 생성 단위 — 유저별, 1시간 타임아웃 시 새로 생성)
  └─ turn (사용자 메시지 1개 → 응답 1개)
        └─ event (처리 단계 하나)
```

- **세션 생성/종료** → `orchestrator.py` 에서 자동 처리 (직접 건드릴 필요 없음)
- **턴 생성/종료** → 동일하게 `orchestrator.py` 에서 자동 처리
- **이벤트 기록** → 각 노드에서 직접 추가 ← 여기가 작업 대상

## EventType 목록

| 상수 | 값 | 사용 시점 |
|---|---|---|
| `USER_MESSAGE` | `"user_message"` | 사용자 메시지 수신 |
| `LLM_INTENT` | `"llm_intent"` | 의도 분류 LLM 호출 |
| `LLM_EXTRACT` | `"llm_extract"` | 파라미터 추출 LLM 호출 |
| `LLM_RESPONSE` | `"llm_response"` | 응답 생성 LLM 호출 |
| `LLM_GENERIC` | `"llm_generic"` | 기타 LLM 호출 |
| `AGENT_ROUTE` | `"agent_route"` | 에이전트 라우팅 결정 |
| `RAG_SEARCH` | `"rag_search"` | 지식베이스 검색 |
| `API_CALL` | `"api_call"` | 외부 API 호출 (MOS 등) |
| `DEVICE_JOB` | `"device_job"` | DeviceJob (Playwright) |
| `HITL_WAIT` | `"hitl_wait"` | 사용자 입력 대기 (interrupt) |
| `HITL_RESUME` | `"hitl_resume"` | 사용자 응답으로 재개 |
| `CHAT_SEND` | `"chat_send"` | Google Chat 응답 전송 |
| `ERROR` | `"error"` | 오류 발생 |
| `COMPLETE` | `"complete"` | 정상 완료 |
| `CANCEL` | `"cancel"` | 취소 |

## 패턴 1 — 단순 이벤트 기록 (add_event)

duration 측정이 필요 없는 단계에 사용.

```python
await add_event(
    session_id,           # state.session_id
    EventType.HITL_WAIT,  # 이벤트 타입
    "ICCID 선택 요청",     # 라벨 (대시보드에 표시되는 이름)
    content="...",        # 선택: 상세 내용
    task_id=state.task_id # 선택: 에이전트 업무일 때만 태깅
)
```

**사용 예시:**
```python
# HITL 대기
async def request_iccid(state: GraphState):
    await add_event(state.session_id, EventType.HITL_WAIT, "ICCID 선택 요청",
                    task_id=state.task_id)
    state.add_ai_message("사용할 ICCID를 선택해주세요.")
    await set_waiting(state, result="ICCID 선택 요청")
    return state

# 취소
async def cancel_task(state: GraphState):
    await add_event(state.session_id, EventType.CANCEL, "업무 취소",
                    task_id=state.task_id)
    await set_cancelled(state, result="사용자 취소")
    return state

# 완료
async def complete_task(state: GraphState):
    await add_event(state.session_id, EventType.COMPLETE, "업무 완료",
                    content="이심 재발급 완료 (1건)", task_id=state.task_id)
    await set_completed(state, result="완료")
    return state
```

## 패턴 2 — duration 측정 이벤트 (session_event)

LLM 호출, API 호출, DeviceJob 등 시간이 걸리는 작업에 사용.
블록 종료 시 duration_ms 자동 계산 및 저장. 예외 발생 시 ERROR 이벤트로 자동 전환.

```python
async with session_event(
    session_id,
    EventType.API_CALL,
    "MOS 사용량 조회 API",
    task_id=state.task_id   # 선택
) as ev:
    result = await some_api_call()
    ev.content = f"{len(result)}건 조회"  # 선택: 결과 요약
    # ev.llm = ...  # LLM 호출일 때만 설정
```

**LLM 호출 예시:**
```python
async with session_event(state.session_id, EventType.LLM_GENERIC, "이심 정보 분석",
                          task_id=state.task_id) as ev:
    llm_response = await (some_prompt | LLM_LIGHT).ainvoke({...})
    result = some_parser.invoke(llm_response)
    ev.content = str(result)[:200]
    ev.llm = build_llm_meta(LLM_LIGHT.model, llm_response.usage_metadata)
```

**API 호출 예시:**
```python
async with session_event(state.session_id, EventType.API_CALL, "이심 발급 API 호출",
                          task_id=state.task_id) as ev:
    response = await esim_client.issue(iccid=iccid)
    ev.content = f"결과: {response.get('status')}"
```

**DeviceJob 예시:**
```python
# 디바이스 잡 요청
async with session_event(state.session_id, EventType.DEVICE_JOB, "DeviceJob 요청",
                          task_id=state.task_id) as ev:
    job_id = await dispatch_device_job(payload)
    ev.content = f"job_id: {job_id}"

# 콜백 수신 후 (별도 노드에서)
await add_event(state.session_id, EventType.DEVICE_JOB, "DeviceJob 완료",
                content=f"결과: {callback_result}", task_id=state.task_id)
```

## 패턴 3 — 에러 처리

`session_event` 블록 내부에서 예외가 발생하면 자동으로 ERROR 이벤트로 기록됨.
수동으로 에러를 기록해야 할 때:

```python
async def some_node(state: GraphState):
    try:
        ...
    except Exception as e:
        await add_event(state.session_id, EventType.ERROR, "API 호출 실패",
                        content=str(e), task_id=state.task_id)
        await set_cancelled(state, result=f"오류: {str(e)}")
    return state
```

## 서브에이전트 노드 작성 체크리스트

새 서브에이전트 node.py 작성 시 각 노드에 아래를 확인:

```
□ 사용자 입력 대기 노드    → add_event(HITL_WAIT)
□ 사용자 재개 노드         → add_event(HITL_RESUME) — interrupt resume 첫 노드
□ 외부 API 호출 노드       → session_event(API_CALL)
□ LLM 호출 노드            → session_event(LLM_GENERIC) + ev.llm 설정
□ DeviceJob 요청 노드      → session_event(DEVICE_JOB)
□ 완료 노드                → add_event(COMPLETE)
□ 취소 노드                → add_event(CANCEL)
□ 에러 처리 블록           → add_event(ERROR)
```

모든 에이전트 관련 이벤트에는 반드시 `task_id=state.task_id` 를 붙여야
대시보드 task 상세에서 실행 시퀀스가 올바르게 조회됩니다.
